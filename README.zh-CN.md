# 十个沙盒试玩 Demo

每款三个递进阶段，手机点击即可采集、制作和建造；人物职业外观、配色、帽子与环境光照有差异。作品围绕实际的资源用途与能力提升设计。

这是一组可继续打磨的完整试玩闭环，并不代表承诺 Loopit A/S 评级。评分还取决于正式手机体验、主题表达和新意。

- 单款 ZIP：根目录 `index.html` 是入口，模型、动画、声音逻辑和页面均在包内，可分别交给 Loopit 导入。
- 合集 ZIP：一个选关大厅和全部十款，适合本地试玩与浏览源码。
- 全部单款 ZIP 合包：解压后选择其中一款 ZIP 导入，适合逐个发布作品。
- 开始按钮开启声音；顶部音符控制静音，暂停菜单可恢复或重开。
- 通关后保存实际场景与战绩的 PNG。系统支持文件分享时可调用原生分享，否则下载图片。
- 本地会保存完成次数与最佳时间，不保存中途进度。

本地运行：在解压目录执行 `python3 -m http.server 8774`，访问 `http://localhost:8774/`。直接双击 HTML 时，浏览器可能阻止读取 GLB，请通过本地服务器或 Loopit 试玩页打开。

人物使用四个 KayKit 基础角色及 Rogue 的兜帽变体，配合服装换色、不同骨骼挂件组合成十种外观。模型与 20 个动作来自已标注的 CC0 素材。源码和素材授权说明均随包提供。
