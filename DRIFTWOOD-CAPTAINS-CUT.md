# Driftwood Deck - Captain's Cut (2.1.0)

A short touch-first survival voyage. Rescue driftwood, build a canopy and a wider deck, counter side swells with real moving cargo, then fit outriggers, an optional cargo net and a working bilge pump. Bring the finished raft home to Lantern Bay.

- Four crossings: 12 / 20 / 27 / 32 seconds, plus moorings and the harbor reveal. Calm opening, then nine increasingly strong side swells and visible rock hazards.
- Drag the scene or bottom rail to steer. Tap cargo left / center / right. Side swells give 2.5 seconds of warning. Cargo recenters after each swell.
- Wood comes from actual floating pickups and successful swell saves. Shore assistance appears only when short of the required build, and is recorded in the rating.
- Cargo position changes the roll. Outriggers reduce actual wave motion. A net prevents wood loss on impact. The pump drains actual floodwater. Wrong counterweight can capsize the raft.
- Quick retry keeps built upgrades and restores the leg's starting supplies; it cannot farm duplicate resources. Replay changes later route placement and swell directions.
- Visible pickup flights, lost timber, lashes, buoy logs, paddling, bracing, curved foam swells, moving ocean, following shadows, harbor crew and sunset arrival. Generated ocean ambience, event sounds and adaptive music respond to mute and pause.
- Results show actual rating / swell saves / rescued wood / score. PNG contains the finished 3D raft. Supporting devices use native file sharing; otherwise the PNG downloads. No automatic recipient send.

## Play / import

Serve this folder over HTTP and open root `index.html`. All required GLBs, embedded textures, skeletal clips, JavaScript and Three.js are local; no API or runtime CDN is required. Do not open via `file://`.

For Loopit, give its creator the individual ZIP download URL and ask it to import root `index.html`, preserve gameplay and all relative asset paths, and make it load before modifying it. Platform import and grading still require verification in Loopit.

Rebuild with `npm install` then `npm run build`. Published ZIP is already built.
